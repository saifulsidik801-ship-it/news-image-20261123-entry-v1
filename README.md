One image that sums up the world's news of Monday 23 November 2026: a
single-page newspaper front page — COP31 collapses in Antalya, the Gulf
crisis deepens around the Strait of Hormuz, BepiColombo reaches Mercury,
and 20 more stories first reported that day — drawn entirely in code with
Pillow. No network, no randomness: every run writes the same bytes.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024x1024, under 1 MiB) to `$MAKEFUN_OUTPUT_DIR`
(default `/output`).
